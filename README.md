# La Scaletta

L'app della band per preparare le prove: il pulsantone estrae le canzoni da ripassare,
segnate quante volte le avete ripassate e quanto bene le sapete, scegliete la cover del mese
e votate le proposte (+1 / −1, un voto a testa).

- **App:** https://alessandrogolinelli.github.io/bandlist/
- **File dell'app:** `index.html` (la configurazione è in cima al file)
- **Regole del database:** `regole-firestore.txt` (da incollare in Firebase › Firestore › Regole)

Finché in `index.html` non c'è la configurazione di Firebase, l'app gira in modalità prova:
funziona tutto, ma i dati restano sul dispositivo di chi la usa.

Per continuare a lavorarci con Claude Code, il contesto del progetto è in `CLAUDE.md`.
